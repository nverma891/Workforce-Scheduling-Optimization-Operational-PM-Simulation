# Workforce-Scheduling-Optimization-Operational-PM-Simulation

An end-to-end operational PM simulation modeling a workforce scheduling optimization solution for a multi-department organization. Using 12 months of simulated payroll data across 5 departments and 3 shift types, the project defines success metrics, builds a forecasting model, and projects the financial impact of reducing overtime.

> **Note:** this is a practice model built entirely on **simulated data**, and its savings figures are projections from assumed inputs. It is a separate project from my MBA capstone (BUS 575 Strategic Management Capstone, Culver-Stockton College), which analyzed a real business's scheduling and payroll data and is not published here.
